# 0.2.0 설치·셸 연동 검증

검증일: 2026-10-27 · 상태: **통과**

[공유용 결과 JSON](evidence/ag-switch-setup-0.2.0.json)

대화형 프로필 생성, 기존 프로필의 `setup`, zsh·bash·fish 별칭·자동완성, PATH 스크립트와 제거를 구현했다. 모든 실험은 전용 임시 저장소·설정 파일·npm prefix에서 수행했다. 사용자 기본 셸 설정을 실험 대상으로 쓰지 않았으며 실제 인증 요청도 보내지 않았다. OAuth 수명주기 검증은 [별도 결과](RESULTS.md)에 보존했다.

## 자동 테스트

기존 55개 검사에 셸 설치·복구·대화형 설정 검사 12개를 추가해 기본 테스트 67개가 됐다. 공식 배포본의 fish 실행 파일을 지정한 전체 실행에서는 fish 검사 1개를 포함해 **68개 모두 통과**했다.

- 이름·명령·별칭·외부 파일 충돌, 심볼릭 링크와 관리 저장소 내부 설치 경로 거부.
- 여러 프로필의 같은 rc 파일 사용, 재설정 시 중복·순서 변경 없음, 제거 후 원문 복원.
- 0600 백업, 원래 rc 권한 유지, 적용 도중 오류 복구와 계획 이후 변경 감지.
- 사용자가 관리 블록·스크립트·파일 권한을 변경했을 때 자동 덮어쓰기·복구 거부.
- 방식 전환 시 이전 rc 블록·스크립트 정리, 인증 데이터 유지.
- 세 셸에서 공백·작은따옴표·달러·백틱·`#`가 포함된 리터럴 경로 실행과 인자 보존, 기본 자동완성 등록.

fish는 이 머신에 설치되지 않아 [공식 릴리스 4.9.3](https://github.com/fish-shell/fish-shell/releases/tag/4.9.3)의 macOS 패키지를 다운로드하고 릴리스 SHA-256과 일치함을 확인했다. 패키지를 임시 디렉터리에 압축만 풀어 실행했으며 시스템 설치는 하지 않았다. 검증한 패키지 SHA-256은 `fb489929e25e66b8c026a1da8935f68f828134e115a1706f360ed73149b843a9`다.

## 설치한 패키지의 실제 실행

`npm pack` 결과를 임시 prefix에 `npm install --global --offline --ignore-scripts`로 설치한 뒤 생성된 `ag-switch` 진입점을 사용했다.

| 검사 | 결과 |
| --- | --- |
| 패키지 버전 | 설치된 명령에서 0.2.0 출력 |
| 실제 PTY 대화형 생성 | 이름·바이너리·both 방식·zsh·rc·bin 디렉터리·최종 확인 입력 후 생성 |
| 실행 | 생성한 외부 스크립트와 zsh 별칭으로 실제 agy 1.4.7의 `--version` 정상 출력 |
| 기존 프로필 setup | zsh both → bash alias → fish alias 전환, 이전 연동 정리 |
| bash·fish 실행 | 각 설정을 읽은 별칭으로 agy `--version` 정상 출력, fish 옵션 완성 확인 |
| doctor | 바이너리·프로필·설정 블록·외부 런처 정상 |
| remove --purge | 등록·런처·데이터 제거, 기존 설정 내용 복원 |
| 최종 적용 거절 | 실제 PTY에서 `n` 입력, 새 저장소·rc 파일 미생성 |
| Ctrl+C | 실제 PTY에서 종료 코드 130, 새 저장소 미생성 |
| private umask | 실제 CLI에서 0644 rc 권한 유지, setup 반복 시 기존 경로·내용 유지 |

시험에 사용한 프로필·패키지 설치 prefix와 임시 설정은 종료 후 삭제했다. 검증용 fish 패키지와 압축 해제 디렉터리도 정리했다. 기본 자동완성은 공개 옵션·명령 제안과 기존 agy 완성 연결이며 모든 하위 명령·값을 포괄하는 검사는 아니다. 다른 파일에서 불러오는 조건부 별칭·함수는 실행해 조사하지 않는다.
